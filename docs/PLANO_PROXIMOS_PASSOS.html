Como rodar localmente (qualquer IDE)

Front: npm ci && npm run dev (porta 5173, precisa de .env a partir do .env.example)
API: cd api && npm ci && npm run dev · testes: npm test (exige as variáveis do api/.env.example)
MCP: npm ci --legacy-peer-deps && npm run build && npm run inspector
Checar tipos do front: npx tsc -p tsconfig.app.json --noEmit

3. Estratégia: primeiros testadores na RMR

Objetivo das próximas 6 semanas: 100 estudantes cadastrados, 40 que fazem a 1ª análise de currículo, 15 entrevistas de feedback. Outubro/novembro é ótimo momento: fim de semestre, gente buscando estágio para 2027.1.
